# Restaurant Management Platform 🍣

A full-stack restaurant ordering and management platform built with FastAPI, SQLAlchemy and MySQL.

The project focuses on building a structured backend architecture for managing users, menu items, orders and payments through REST APIs.

## 🛠 Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy 2.x
- MySQL / MariaDB
- Alembic
- Pydantic

### Frontend
- HTML
- CSS
- Bootstrap
- JavaScript

## ✨ Features

- User registration and authentication
- Menu management
- Shopping cart
- Order creation and management
- Payment workflow
- Administrative functionality
- RESTful API architecture

## 🚧 Project Status

Currently under active development.

Additional features, API documentation, database diagrams and deployment instructions will be added as the project evolves.

## 🎯 Project Goal

This project was created to practice and demonstrate backend development skills, including relational database design, REST API development, authentication, database migrations and full-stack integration.
